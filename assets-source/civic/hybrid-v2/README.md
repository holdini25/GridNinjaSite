# Civic hybrid v2 native source

`scene.py` creates a new editable, metre-scale fictional architectural scene.
It does not reconstruct either `generated-v1` raster master. The facility, grid
yard and neighborhood are independent parcels, with no depicted service export,
live control, operating authority or community outcome.

The source includes three paired camera studies. Each pair shares the same site,
architecture, equipment, lighting and seed. Native PNGs are geometry and lighting
plates for a hybrid finishing process; they are not independently approved
publication assets. Preserve generated finishing inputs, outputs and tool receipts
separately and identify the final medium honestly as hybrid artwork.

The selected architectural revision has a 180×108 m footprint and a 21.9 m
parapet. Its opaque hall wings have recessed louvers and deep fins; glazing is
concentrated in the central atrium and entrance. Exactly **three cooling banks**
contain eight assemblies each. Human-scale entry doors and canopy do not stretch
when the main hall becomes taller. Both cameras use this same geometry.

Run from the repository root:

```sh
python3 scripts/civic/run-hybrid.py --output build/civic-hybrid/studies-new --timeout 1800 -- --mode studies
python3 scripts/civic/run-hybrid.py --output build/civic-hybrid/final-new --timeout 1800 -- --mode final --family A-shared-landscape
python3 scripts/civic/run-hybrid.py --output build/civic-hybrid/reference-new --timeout 1800 -- --mode reference --family A-shared-landscape
```

Use a fresh output directory for every attempt. The supervisor exclusively claims
the existing repository compute and render locks, retains bounded logs, terminates
the process group after a finite timeout, and preserves ownership locks if child
termination cannot be confirmed. No CPU fallback or global preference save occurs.
Metal binary archive fallback is not automatic; investigate a recorded failure
before extending the renderer's behavior.

Studies use 32 samples at 960×540 and 600×720. Finals use up to 256 samples at
3840×2160 and 1360×1632; references use 512 samples at the same dimensions.
Final/reference adaptive threshold is 0.005. Receipts record the actual Blender
version, enabled device, source and output hashes, timings and color settings.
The display master is 16-bit sRGB PNG through AgX; the accompanying EXR is
32-bit scene-linear RGBA. Both preserve the original native output, before
generated editing, grading or delivery compression.

The selected native handoff is archived under `native/final-03`. Its original
render and process receipts remain byte-identical, including their original
private build paths. `archival-receipt.json` maps those paths to retained files
with exact hashes and sizes. Restore the original paths byte-for-byte to rerun
the current packager; do not rewrite a render receipt to imply that Blender
originally rendered into the archive. Earlier 512-sample references checked the
preceding geometry and remain historical evidence, not a matched reference for
this architectural revision.

Source changes require a new native render and matching receipt. Published civic
releases must never be overwritten; delivery uses the separate versioned package
workflow. Review finished landscape and portrait together in the actual HTML
layout, including its copy overlay, edge fades and synthetic qualification.
